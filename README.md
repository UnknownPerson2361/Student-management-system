# 🎓 Student Management System

A simple and powerful Student Management System built with Python.

## ✨ Features

- ➕ Add Student
- 👀 View All Students
- 🔍 Search Student
- ✏️ Update Student
- 🗑️ Delete Student
- 📝 Add Subject Marks
- 📊 Calculate Percentage
- 🏆 Generate Student Grade
- 💾 Store Student Data in JSON

## 🛠️ Technologies

- Python 3
- JSON
- File Handling
